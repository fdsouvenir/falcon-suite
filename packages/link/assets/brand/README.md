# Sign-in button artwork

These files are the providers' official sign-in artwork, copied unmodified.

- `google-signin-light-square.svg` — "Sign in with Google" (light theme, square, with text) from
  Google's sign-in branding assets (signin-assets.zip):
  https://developers.google.com/identity/branding-guidelines
- `microsoft-signin-light.svg` — "Sign in with Microsoft" (light) and `microsoft-logo.svg` — the
  Microsoft logo, from https://learn.microsoft.com/entra/identity-platform/howto-add-branding-in-apps

- `hubspot-logo.svg` — the HubSpot sprocket in HubSpot orange (#FF7A59). Path data from
  Simple Icons 16.36.0 (`icons/hubspot.svg`, CC0 data; source listed as
  https://www.hubspot.com/style-guide). HubSpot is a trademark of HubSpot, Inc.; the mark only
  identifies the integration. HubSpot publishes no sign-in button artwork, so the page keeps a
  plain "Connect to HubSpot" button.
- `dropbox-glyph.svg` — the Dropbox glyph in Dropbox blue (#0061FE), unmodified
  `Logos/Dropbox/Glyph/Glyph_128.svg` from Dropbox's Brand Partner Toolkit, linked as the approved
  logos from https://brand.dropbox.com/ (the developer branding guide,
  https://docs.dropboxapi.com/dropbox-api/docs/developer-resources/branding-guide, points there).
  Dropbox is a trademark of Dropbox, Inc.; the glyph only identifies the integration and doesn't
  imply that Dropbox endorses Falcon Link. Dropbox publishes no sign-in button kit, so the page
  shows the glyph next to its own "Sign in with Dropbox" button.
- `zoominfo-logomark.svg` — the ZoomInfo logomark (white mark on ZoomInfo red, #EA1B15), unmodified
  from ZoomInfo's own website: https://www.zoominfo.com/logos/acquisitions/zoominfo/zoominfo-red-logomark.svg
  (downloaded 2026-10-30). ZoomInfo's official digital-asset library (https://brandfolder.com/zoominfo)
  needs a sign-in, so the mark comes from the site ZoomInfo publishes. ZoomInfo is a trademark of
  ZoomInfo; the mark only identifies the integration and doesn't imply that ZoomInfo
  endorses Falcon Link. ZoomInfo publishes no sign-in button artwork, so the page shows the mark next
  to its own "Sign in with ZoomInfo" button.
- `stripe-link-logo.svg` — the Link mark (dark arrow on Link green, #00D66F), unmodified
  `assets/link.svg` from Stripe's link-cli repository (https://github.com/stripe/link-cli,
  tag `@stripe/link-cli@1.5.1`, MIT). Link is a Stripe product and trademark; the mark only
  identifies the integration and doesn't imply that Stripe endorses Falcon Link. Stripe publishes
  no sign-in button artwork for link-cli, so the page shows the mark next to its own "Sign in with
  Stripe Link" button.
- `google-health-heart.png` — the Google Health heart, unmodified `Google_Health_logos/Icon_Rounded.png`
  (256 × 256, transparent) from Google's Google Health logo pack,
  https://developers.google.com/static/health/resources/Google_Health_logos.zip, linked as the
  approved logos from https://developers.google.com/health/promote (downloaded 2026-11-16). That
  page asks integrations to use the Google Health name and logo, not Fitbit or Google Fit artwork.
  Google publishes no SVG, so Link bundles the PNG. Google Health is a trademark of Google LLC; the
  mark only identifies the integration and doesn't imply that Google endorses Falcon Link. Sign-in
  is with a Google account, so the page uses `google-signin-light-square.svg` (above) as its
  sign-in button.
- `whatsapp-glyph.svg` — the WhatsApp glyph in WhatsApp green (#25D366), unmodified
  `01_Glyph/01_Digital RGB/03_SVG/Digital_Glyph_Green_RGB_2026.svg` from the logo pack
  (`WhatsApp-Brand-Resource-Center.zip`, downloaded 2026-11-16) on WhatsApp's brand page at Meta's
  Brand Resource Center: https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/ (where
  https://www.whatsapp.com/brand points). WhatsApp is a trademark of WhatsApp LLC; the glyph only
  identifies the integration and doesn't imply that WhatsApp or Meta endorses Falcon Link or
  wacli. Linking uses a QR code or pairing code shown on Link's own page, so there is no sign-in
  button artwork.
